🎮 Mario Bros Ionic Game
Acesse o site para jogar:
🔗 https://mario-bros-ionic.netlify.app

📱 Projeto
Este é um jogo inspirado no universo do Mario Bros, desenvolvido com Ionic + React.
A aplicação é totalmente responsiva e foi criada no início do 3º semestre do curso de Análise e Desenvolvimento de Sistemas (2024).

🚀 Como rodar localmente
Siga os passos abaixo após clonar este repositório ou baixar o arquivo .zip:

Abra a pasta do projeto no terminal de sua escolha.

Execute o comando:

bash
Copiar
Editar
ionic serve
O navegador será aberto automaticamente.

Para jogar, siga as instruções exibidas abaixo do contêiner do Mario no próprio jogo.

Você pode jogar no tamanho normal do navegador ou ajustar conforme sua preferência.

🛠️ Tecnologias e Ferramentas
React 18

Ionic React 8

React Router 5

Vite

TypeScript

ESLint

Vitest & Cypress (testes)
